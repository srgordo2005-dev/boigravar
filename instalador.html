🔄 RESET DE FÁBRICA:
Para resetar a placa e apagar tudo, basta clicar no botão de Instalar acima e, quando a tela aparecer, marcar a caixinha "Erase device" (Apagar dispositivo). Isso vai zerar toda a memória do Boi.
Problemas para reconhecer a placa?
Se o Chrome não achar a Porta COM, você precisa instalar os drivers USB do seu computador:

- Baixar Driver CH340 (Placas Pretas)
- Baixar Driver CP210x (Placas Azuis)
Aviso Importante: Após a gravação terminar, o ESP32 vai ligar, criar a rede Wi-Fi e mandar o seu MAC Address lá no Bot do Telegram para você liberar o uso!
