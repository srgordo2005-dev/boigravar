Problemas para reconhecer a placa?
Se o Chrome não achar a Porta COM, você precisa instalar os drivers USB do seu computador:

- Baixar Driver CH340 (Placas Pretas)
- Baixar Driver CP210x (Placas Azuis)
Aviso Importante: Após a gravação terminar, o ESP32 vai ligar, criar a rede Wi-Fi e mandar o seu MAC Address lá no Bot do Telegram para você liberar o uso! (Como o ESP32 entra vazio, só depois da gravação concluída é que ele consegue mandar a mensagem pelo Telegram avisando que foi gravado/ativado).
